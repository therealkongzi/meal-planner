# Family Dinners

A single-file, offline web app for planning a family's weekly dinners (4 people), building a shopping list, and estimating macros.

- **Plan:** 7 nights per week (start day set in Settings), leftovers / eating-out nights, per-night servings.
- **Meals:** 42 built-in family dinners (including Filipino and Tex-Mex), plus your own meals with macro estimates.
- **Macros:** estimated from an embedded table of 271 common ingredients (per 100 g, based on USDA FoodData Central standard values) with unit conversions.
- **Shopping list:** generated from the week's plan, combined and grouped by store section; manual items are kept when it is remade.
- **Ideas:** filter and rank by goal, auto-fill empty nights, and copy a recipe request for a health-coach chat.

All data stays in the browser (localStorage). Use Settings → Export JSON to back up.

Live: https://therealkongzi.github.io/meal-planner/
